# Wiser-2026 Moderna Challenge

One of the constraints on the parameter landscape is that the parameters are continuous functions of the parameters. One can exploit such constraints to guide their parameter optimisation decision to reach global minima early. Inspired by some recent work on Fourier approximation of the parameter landscape. I implement the shared code to improve QAOA performance where parameters are interpolated from an approximated version of the landscape using Chebyshev polynomials.

The uploaded .ipynb file contains comments along with code to help understand the function of various parts of the code.
